# Danh sách từng API chưa triển khai và nguyên nhân cụ thể

Ngày tổng hợp: 13/11/2026. Phạm vi: **25 API chưa có xử lý nghiệp vụ** trong tổng số 92 thao tác của đặc tả. Mỗi dòng dưới đây tương ứng một API riêng biệt.

Các API này đã được đăng ký route nhưng có `action: unsupported` trong [catalog.ts](../../apps/api/src/spec/catalog.ts). [SpecService](../../apps/api/src/spec/service.ts) chủ động trả HTTP **501**, mã nghiệp vụ **5010**, sau bước xác thực/phân quyền áp dụng cho API riêng tư. Vì vậy, “chưa triển khai” ở đây có nghĩa chưa có chức năng, không phải thiếu đường dẫn API.

Cơ sở đối chiếu: [đặc tả MayDay](../MayDay.md), mã nguồn hiện tại, [Prisma schema](../../apps/api/prisma/schema.prisma), [snapshot schema](../../apps/api/src/native/schema.json) và kết quả kiểm tra database thực tế qua cấu hình `.env` ngày 12/11/2026 trong [báo cáo đối chiếu](../API_IMPLEMENTATION_AUDIT.vi.md). Không kết nối lại database khi viết tài liệu này. Lần kiểm tra trước xác nhận có 44 bảng và 1 view; các thực thể thiếu bên dưới không có trong schema đã kiểm tra. Tên bảng tiếng Anh được dùng để đối chiếu thiết kế và đề xuất; có thể triển khai tên tương đương, không bắt buộc đổi tên các bảng hiện hữu.

**Lưu ý về nguyên nhân:** 18/25 API phụ thuộc hệ biểu mẫu/câu trả lời động. Các API còn lại phụ thuộc kho mã khôi phục, mô hình chỉ định xét nghiệm, mô hình thông báo/token thiết bị hoặc chính sách xóa hồ sơ. Vì thế, không thể hoàn tất toàn bộ chỉ bằng sửa `.env` hoặc thêm bảng: vẫn cần handler, phân quyền, quy tắc nghiệp vụ và tích hợp dịch vụ tương ứng. Các mục “cần bổ sung” là đề xuất kỹ thuật, chưa phải migration hay thay đổi đã thực hiện.
